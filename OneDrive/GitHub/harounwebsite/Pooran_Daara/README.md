# Pooran Daara — منصة اجتماعية متعددة اللغات

مشروع ويب متكامل باستخدام **Python + Django + Django Channels**. يعمل محلياً بقاعدة SQLite، ويدعم التوسع لاحقاً باستخدام PostgreSQL وRedis.

## الوظائف المكتملة

### المجتمع والمنشورات
- إنشاء حساب، تسجيل الدخول والخروج.
- ملف شخصي، صورة، نبذة، موقع، لغة مفضلة، وعلامة توثيق.
- نشر النصوص والصور، تعديلها وحذفها.
- التعليقات والإعجابات.
- البحث عن المستخدمين والمنشورات.
- إخفاء المنشورات الموقوفة أو المخالفة من النتائج العامة.

### المحادثات والإشعارات
- محادثات مباشرة خاصة بين مستخدمين.
- إرسال فوري باستخدام WebSocket.
- حفظ جميع الرسائل في قاعدة البيانات.
- إرسال عادي احتياطي إذا تعذر WebSocket.
- إشعارات فورية للإعجاب والتعليق والرسائل وقرارات الإدارة.
- عداد للإشعارات والرسائل غير المقروءة.

### الأمان والإشراف
- حظر مستخدم وإلغاء الحظر.
- منع المحادثات وإخفاء محتوى الطرف المحظور.
- الإبلاغ عن منشور، مستخدم، تعليق أو رسالة.
- لوحة إشراف مستقلة على المسار `/control/`.
- حل البلاغات أو رفضها.
- إخفاء المنشورات أو استعادتها أو حذفها من العرض.
- تعليق حساب المستخدم وإعادة تفعيله مع تسجيل السبب.
- سجل لجميع إجراءات المشرفين.
- لوحة Django الأصلية على `/admin/`.

### اللغات
واجهة رئيسية بثلاث لغات:
- العربية.
- English.
- Français.

يستطيع المستخدم تغيير اللغة من أعلى الصفحة، وتحفظ اللغة في الجلسة والملف الشخصي.

### الذكاء الاصطناعي
صفحة `/ai/` تشمل:
- مساعد لاستخدام المنصة.
- ترجمة بين العربية والإنجليزية والفرنسية.
- تحليل أولي لمخاطر المحتوى.
- تخزين سجل استخدام أدوات الذكاء الاصطناعي للمستخدم.

يوجد وضعان:

1. **Local**: يعمل دون مفتاح API. المساعد والترجمة محدودان، والتحليل يعتمد على قواعد أولية.
2. **OpenAI**: ترجمة ومساعدة وتحليل أكثر تقدماً عند وضع `OPENAI_API_KEY` وتغيير `AI_PROVIDER=openai`.

> التحليل الآلي ليس حكماً نهائياً، وقد يخطئ. لذلك المحتوى عالي الخطورة يرسل للمراجعة البشرية بدلاً من حذفه نهائياً تلقائياً.

## التشغيل على Windows PowerShell

يفضل Python 3.11 للمشروع:

```powershell
cd "C:\مسار\Pooran_Daara"

python -m venv venv311
.\venv311\Scripts\Activate.ps1

python -m pip install --upgrade pip
python -m pip install -r requirements.txt

Copy-Item .env.example .env
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

افتح:

```text
http://127.0.0.1:8000/
```

لوحة الإشراف داخل الموقع:

```text
http://127.0.0.1:8000/control/
```

لوحة Django:

```text
http://127.0.0.1:8000/admin/
```

## تشغيل الذكاء الاصطناعي المتقدم

افتح ملف `.env` وعدّل:

```env
AI_PROVIDER=openai
OPENAI_API_KEY=ضع_المفتاح_هنا
OPENAI_MODEL=gpt-5.6
```

ثم أعد تشغيل السيرفر. لا تكتب المفتاح داخل ملفات Python ولا ترفعه إلى GitHub.

## المحادثات الفورية

في التطوير المحلي لا تحتاج Redis؛ المشروع يستخدم طبقة ذاكرة داخل عملية واحدة.

للنشر على أكثر من عملية أو خادم، شغّل Redis وضع في `.env`:

```env
REDIS_URL=redis://127.0.0.1:6379/0
```

بعد ذلك يستخدم المشروع `channels_redis` تلقائياً.

## قبل النشر الحقيقي

- اجعل `DJANGO_DEBUG=False`.
- أنشئ `DJANGO_SECRET_KEY` قوياً وسرياً.
- ضع اسم النطاق في `DJANGO_ALLOWED_HOSTS`.
- استخدم PostgreSQL بدلاً من SQLite عند زيادة المستخدمين.
- استخدم Redis للمحادثات والإشعارات عند تشغيل أكثر من process.
- استخدم HTTPS.
- استخدم تخزيناً سحابياً آمناً للصور.
- أضف تحقق البريد، استعادة كلمة المرور، وسياسة خصوصية وشروط استخدام.
- راجع قواعد تحليل المحتوى بواسطة مختصين قبل الاعتماد عليها في الإنتاج.
