# Smart_AI_Glasses

مشروع كامل للنظارات الذكية بالذكاء الاصطناعي.

## تشغيل المشروع

1) افتح CMD داخل مجلد المشروع.

2) ثبت المكتبات:

```bash
pip install -r requirements.txt
```

3) شغل البرنامج:

```bash
python main.py
```

## ترتيب التشغيل الصحيح

1. جرب الكاميرا من الخيار 1.
2. أنشئ قاعدة بيانات تجريبية من الخيار 2.
3. سجل شخص والتقط صور من الخيار 3.
4. درب نموذج الوجوه من الخيار 4.
5. شغل التعرف على الأشخاص من الخيار 5.

## بيانات الدخول التجريبية

في security.py:
- username: admin
- password: 1234

## ملاحظات مهمة

- ملف person_recognition.py بدل face_recognition.py لتجنب التعارض مع مكتبة face_recognition.
- لو ظهرت مشكلة cv2:
  ```bash
  pip uninstall opencv-python -y
  pip install opencv-contrib-python
  ```
- لو الكاميرا لا تعمل، أغلق Camera App أو Zoom أو Teams.


## تشغيل النظام الكامل

بعد تثبيت المكتبات وتشغيل قاعدة البيانات، يمكنك تشغيل النظام الكامل:

```bash
python full_system.py
```

أو من القائمة:

```bash
python main.py
```

ثم اختر:

```text
12. Run FULL Smart Glasses System
```

## أزرار النظام الكامل

داخل نافذة الكاميرا:

```text
P = تشغيل/إيقاف التعرف على الأشخاص
O = تشغيل/إيقاف كشف الأشياء
E = تشغيل/إيقاف تحليل المشاعر
T = قراءة النص من الكاميرا OCR
R = ترجمة آخر نص تمت قراءته
S = نطق آخر نص أو ترجمة
M = حفظ آخر نص كملاحظة اجتماع
Q = خروج
```

## ملاحظة

بعض الخصائص تحتاج مكتبات ثقيلة أو إعدادات إضافية:

- Object Detection يحتاج ultralytics وملف YOLO.
- Emotion يحتاج deepface.
- OCR يحتاج pytesseract وبرنامج Tesseract OCR مثبت في Windows.
- Speech يحتاج مايكروفون يعمل.


## الترجمة الصوتية المباشرة - 4 لغات

تمت إضافة ملف جديد:

```text
live_voice_translator.py
```

يدعم الترجمة الصوتية المباشرة بين 4 لغات:

```text
1. العربية
2. الإنجليزية
3. الفرنسية
4. الإسبانية
```

### تشغيل الترجمة الصوتية فقط

```bash
python live_voice_translator.py
```

مثال:
- اختر لغة الكلام: العربية
- اختر لغة الترجمة: الفرنسية
- قل: صباح الخير
- النظام يحول الصوت إلى نص ثم يترجمها وينطقها بالفرنسية: Bonjour

### تشغيلها من القائمة الرئيسية

```bash
python main.py
```

ثم اختر:

```text
13. Live voice translator - ترجمة صوتية مباشرة
```

### مكتبات الترجمة الصوتية

تمت إضافة:

```text
gTTS
pygame
```

إذا ظهر خطأ في المايكروفون على Windows، جرّب:

```bash
pip install pipwin
pipwin install pyaudio
```

أو:

```bash
pip install PyAudio
```

ملاحظة: الترجمة والنطق باستخدام gTTS يحتاجان إنترنت.


## الترجمة بدون مايكروفون

إذا جهازك لا يحتوي على مايكروفون، استخدم الملف:

```bash
python no_mic_translator.py
```

أو من القائمة الرئيسية:

```bash
python main.py
```

ثم اختر:

```text
14. No microphone translator - ترجمة بدون مايكروفون
```

### الوضع الأول: كتابة النص ثم النطق

لا يحتاج مايكروفون.

مثال:
- اختر لغة النص: العربية
- اختر لغة الترجمة: الفرنسية
- اكتب: صباح الخير
- النظام يترجم: Bonjour
- ثم ينطقها من سماعة الجهاز أو سماعة البلوتوث.

### الوضع الثاني: ملف صوت من التلفون

إذا عندك تلفون:
1. سجل صوتك في التلفون.
2. حول أو احفظ الملف بصيغة WAV.
3. انقل الملف إلى مجلد sounds.
4. شغل no_mic_translator.py.
5. اختر Audio file WAV.
6. اكتب اسم الملف مثل input.wav.

النظام سيقرأ الملف، يحوله إلى نص، يترجمه، ثم ينطق الترجمة.
