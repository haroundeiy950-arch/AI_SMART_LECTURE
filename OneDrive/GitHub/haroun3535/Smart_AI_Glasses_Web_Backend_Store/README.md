# Smart AI Glasses Web Platform

مشروع ويب مستقل لنظام نظارات ذكية، مصمم كقاعدة احترافية قابلة للتطوير إلى مشروع تخرج. يعمل داخل المتصفح بدل قائمة PowerShell ويحتوي على تسجيل دخول وكلمة مرور، Windows Hello/Passkeys، كاميرا مباشرة، مساعد صوتي، ترجمة، اجتماعات، تسجيل أشخاص، سجلات أمان ونسخ احتياطي.

## المميزات الموجودة

- صفحة Login احترافية بجلسة آمنة وتشفير Argon2 لكلمات المرور.
- إيقاف مؤقت بعد خمس محاولات دخول فاشلة خلال خمس دقائق.
- Windows Hello / بصمة / PIN عبر WebAuthn Passkey.
- Dashboard وإحصاءات.
- AI Voice: كتابة أو تسجيل ميكروفون، تفريغ صوت، رد AI وصوت طبيعي.
- وضع احتياطي: صوت المتصفح يعمل عندما لا يوجد API key.
- كاميرا المتصفح وتحليل لقطة: وصف المشهد، الأشياء، OCR، عدد الأشخاص، تعبير مرئي عام وتنبيهات سلامة.
- تسجيل الأشخاص مع صورة من كاميرا المتصفح.
- ترجمة متعددة اللغات مع قراءة صوتية.
- مساعد اجتماعات للتلخيص واستخراج المهام.
- SQLite لحفظ المستخدمين والأشخاص والاجتماعات والمحادثات وسجل الدخول.
- نسخة احتياطية ZIP لا تحتوي على ملف `.env` أو مفتاح API.

## التشغيل السريع على Windows 11

### الطريقة الأسهل

اضغط مرتين على:

```text
start.bat
```

أو من PowerShell:

```powershell
cd "C:\path\to\Smart_AI_Glasses_Web"
.\start.ps1
```

### التشغيل اليدوي

```powershell
cd "C:\path\to\Smart_AI_Glasses_Web"
py -3.11 -m venv venv311
.\venv311\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python run.py
```

افتح فقط:

```text
http://localhost:8000
```

بيانات الدخول الأولية:

```text
Username: admin
Password: ChangeMe@12345
```

غيّر كلمة المرور فورًا من **الأمان والإعدادات**.

## تفعيل AI Voice القوي

افتح `.env` وأضف المفتاح في الخادم فقط:

```env
OPENAI_API_KEY=your_key_here
```

لا تضع المفتاح داخل ملفات JavaScript أو GitHub. بعد الحفظ أوقف الخادم وشغله من جديد.

بدون المفتاح يعمل:

- Login وDashboard.
- الكاميرا وحفظ اللقطات.
- تسجيل الأشخاص.
- الاجتماعات بتلخيص محلي بسيط.
- صوت المتصفح الاحتياطي.

مع المفتاح يعمل أيضًا:

- المساعد الذكي الكامل.
- تحويل التسجيل الصوتي إلى نص.
- الصوت الطبيعي عالي الجودة.
- تحليل الصورة وOCR والأشياء.
- الترجمة والتلخيص المتقدم.

## تسجيل البصمة / Windows Hello

1. ادخل أولًا باسم المستخدم وكلمة المرور.
2. افتح **الأمان والإعدادات**.
3. اضغط **تسجيل Windows Hello لهذا الحساب**.
4. أكمل نافذة Windows Hello بالبصمة أو PIN.
5. سجّل الخروج.
6. اكتب `admin` في صفحة Login ثم اضغط دخول بالبصمة.

مهم:

- افتح النظام من `http://localhost:8000` وليس عنوان IP مختلف.
- يجب أن يكون Windows Hello مضبوطًا في Windows Settings.
- لا تجعل البصمة وسيلة الدخول الوحيدة؛ احتفظ بكلمة مرور استرداد.

## تفعيل التعرف المحلي على الوجوه

المحرك موجود داخل `app/face_service.py` لكنه اختياري حتى لا يجعل التثبيت الأساسي ثقيلًا. ثبّت نسخة الرؤية:

```powershell
python -m pip install -r requirements-vision.txt
```

ثم:

1. افتح صفحة **الأشخاص**.
2. سجل الشخص وصورته.
3. افتح الكاميرا واضغط **التقاط 20 صورة** بجانب اسمه.
4. حرّك الوجه قليلًا بين العينات وحافظ على إضاءة جيدة.
5. اضغط **تدريب نموذج الوجه**.
6. افتح صفحة الكاميرا واضغط **تحليل المشهد**.

سيستخدم النظام OpenCV Contrib وLBPH، ويعرض الاسم ونسبة تطابق تقريبية. ملفات التدريب تحفظ هنا:

```text
data/known_faces/<PERSON_CODE>/sample_001.jpg
models/face_recognition/lbph_model.yml
models/face_recognition/labels.json
```

`UNKNOWN_THRESHOLD` موجود داخل `app/face_service.py` ويمكن تعديله بعد الاختبار.

## النشر النهائي

عند تشغيل النظام خارج الكمبيوتر المحلي:

- استخدم HTTPS.
- غيّر `SECRET_KEY` وبيانات المدير.
- اجعل `SECURE_COOKIES=true`.
- عدّل `ORIGIN` و`WEBAUTHN_RP_ID` إلى الدومين الحقيقي.
- استخدم PostgreSQL بدل SQLite للمستخدمين المتعددين.
- ضع Reverse Proxy مثل Nginx أو خدمة نشر تدعم HTTPS.
- أنشئ سياسة موافقة واضحة للكاميرا والميكروفون وحفظ الصور.

## سيناريو العرض أمام لجنة التخرج

1. تسجيل دخول بكلمة المرور.
2. تسجيل Windows Hello ثم تسجيل الخروج والدخول بالبصمة.
3. تشغيل الكاميرا وتحليل مشهد يحتوي على شخص وكتاب وهاتف ونص.
4. سؤال AI Voice باللغة العربية وتشغيل الرد بصوت طبيعي.
5. ترجمة الرد إلى الإنجليزية أو الفرنسية أو Kinyarwanda.
6. إدخال نص اجتماع، تلخيصه واستخراج المهام.
7. عرض الأشخاص المسجلين وسجل محاولات الدخول.
8. تنزيل نسخة احتياطية من البيانات.

## تنبيه

هذه قاعدة عمل احترافية وليست جهاز نظارة مكتملًا. جودة التعرف المباشر تعتمد على محرك الرؤية، عدد صور التدريب، الإضاءة، الكاميرا، ونموذج AI المستخدم. يجب اختبار كل وحدة على جهاز العرض قبل المناقشة.

## Backend وإدارة المنتجات

أضيفت ثلاث صفحات جديدة:

- `/backend` مركز تحكم المدير وإحصاءات النظام.
- `/backend/products` رفع وتعديل وإخفاء وحذف المنتجات.
- `/products` سوق المنتجات للمستخدمين.

حقول المنتج تشمل: الاسم، الفئة، السعر، العملة، الكمية، الحالة، الموقع، WhatsApp، الوصف والصورة. الصور المقبولة JPG وPNG وWEBP بحجم أقصى 5MB، وتُحفظ داخل `data/product_images`.

بعد تحديث نسخة قديمة، أوقف السيرفر ثم شغّله مرة أخرى. `SQLAlchemy` سينشئ جدول `products` تلقائيًا داخل قاعدة SQLite الحالية.
