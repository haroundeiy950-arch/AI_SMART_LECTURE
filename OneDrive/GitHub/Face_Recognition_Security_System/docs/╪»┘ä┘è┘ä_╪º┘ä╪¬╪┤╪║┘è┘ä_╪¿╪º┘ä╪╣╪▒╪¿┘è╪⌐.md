# دليل تشغيل نظام التعرف على الوجه الأمني

## 1. متطلبات التشغيل

- Windows 10 أو Windows 11.
- Python 3.11 أو 3.12 أو 3.13.
- كاميرا اللابتوب أو كاميرا USB.
- إضاءة جيدة أمام الوجه.
- اتصال بالإنترنت مطلوب فقط عند تثبيت المكتبات أول مرة.

## 2. التشغيل السريع

1. فك ضغط الملف.
2. افتح مجلد `Face_Recognition_Security_System`.
3. شغّل الملف `run_windows.bat`.
4. سيُنشئ البرنامج بيئة Python خاصة ويثبت المكتبات.
5. بعد انتهاء التثبيت ستظهر نافذة تسجيل الدخول.

## 3. بيانات الدخول الأولى

```text
اسم المستخدم: admin
كلمة المرور: 
```

يجب تغيير كلمة المرور مباشرة من صفحة `Settings`.

## 4. تسجيل شخص جديد

1. افتح صفحة `Register Person`.
2. أدخل رقم الشخص مثل `EMP-001`.
3. أدخل الاسم الكامل.
4. أدخل القسم ورقم الهاتف والملاحظات إن وجدت.
5. اضغط `Save Person and Capture Face`.
6. ستفتح الكاميرا وتلتقط 30 صورة.
7. حرّك الرأس قليلاً إلى اليمين واليسار.
8. لا تسمح بظهور شخص آخر داخل الكاميرا أثناء التسجيل.
9. بعد انتهاء الالتقاط سيتم تدريب النموذج تلقائياً.

## 5. تشغيل التعرف والحضور

1. افتح صفحة `Live Recognition`.
2. اختر:
   - `IN` لتسجيل الدخول أو الحضور.
   - `OUT` لتسجيل الخروج أو الانصراف.
3. اضغط `Start Camera`.
4. الوجه المعروف يظهر بإطار أخضر.
5. الوجه غير المعروف يظهر بإطار أحمر وتُحفظ صورته.
6. اضغط حرف `Q` داخل نافذة الكاميرا لإيقافها.

## 6. إدارة الأشخاص

من صفحة `People` يمكنك:

- البحث بالاسم أو الرقم أو القسم.
- تعديل معلومات الشخص.
- تعطيل صلاحية الشخص بدون حذف صوره.
- حذف الشخص وسجلاته من قاعدة البيانات.

## 7. التقارير

من صفحة `Attendance`:

- أدخل تاريخ البداية والنهاية بالشكل `YYYY-MM-DD`.
- اضغط `Filter`.
- اضغط `Export CSV` لإنشاء التقرير.
- يمكن فتح التقرير في Excel.

من صفحة `Unknown Events`:

- راجع صور الأشخاص غير المعروفين.
- اضغط مرتين على السجل لفتح الصورة.
- ضع السجل كـ `Reviewed` بعد المراجعة.
- صدّر تقريراً بصيغة CSV.

## 8. ملفات النظام

```text
data/security_system.db       قاعدة البيانات
data/faces/                   صور الأشخاص المسجلين
data/unknown/                 صور الأشخاص غير المعروفين
models/lbph_face_model.yml    نموذج التعرف المدرب
reports/                      التقارير
backups/                      النسخ الاحتياطية
```

## 9. حل مشكلة cv2.face

إذا ظهر الخطأ:

```text
module 'cv2' has no attribute 'face'
```

نفّذ الأوامر التالية داخل بيئة المشروع:

```powershell
python -m pip uninstall -y opencv-python opencv-python-headless opencv-contrib-python-headless opencv-contrib-python
python -m pip install opencv-contrib-python
```

لا تثبت `opencv-python` و`opencv-contrib-python` معاً داخل نفس البيئة.

## 10. حل مشكلة الكاميرا

- أغلق تطبيق Camera وZoom وTeams والمتصفح.
- افتح إعدادات Windows.
- اذهب إلى Privacy & security ثم Camera.
- اسمح لتطبيقات سطح المكتب باستخدام الكاميرا.
- غيّر `CAMERA_INDEX` داخل `config.py` من 0 إلى 1 عند الحاجة.

## 11. ملاحظات أمنية مهمة

هذا المشروع مناسب للتعليم والتجارب والمكاتب الصغيرة. قبل استخدامه في مكان حساس يجب إضافة:

- كشف الحيوية لمنع استخدام صورة أمام الكاميرا.
- بطاقة أو PIN أو OTP كعامل تحقق ثانٍ.
- تشفير قاعدة البيانات والصور.
- صلاحيات متعددة للمسؤولين.
- سياسة موافقة وحذف للبيانات البيومترية.
- اختبار الدقة مع الإضاءة والكاميرات الحقيقية.
- ربط آمن بوحدة التحكم في الباب.
